This guide walks you through the process of Using this REST APPLICATION.


### Parse Page Data and Store in DB ###

----
http://localhost:8080/data/
----

with payload:

[source,json]
----
{
	"url":"https://www.google.com"
}
----


and respond with a link:/understanding/JSON[JSON] representation of a data about Page and Sentiment Analysis:

[source,json]
----
{
    "page_title": "Google",
    "description": "Search the world's information, including webpages, images, videos and more. Google has many special features to help you find exactly what you're looking for.",
    "author": "unknown",
    "polarity": "negative",
    "subjectivity": "subjective",
    "text": "Choose the privacy settings that are right for you",
    "polarity_confidence": 0.4907958507537842,
    "subjectivity_confidence": 1,
    "url": "https://www.google.com"
}
----


### Retrieve Page Data from DB ###

----
http://localhost:8080/data?url=https://www.netflix.com
----

The response to get GET REQUEST is JSON representation of Page Data stored in the database for the Url:

### HTTPS Status Codes ###
The application supports following HTTPS Status Codes:
----
- 200 OK Success
- 400 Bad Request, if request contains invalid arguments.
- 403 Forbidden, if data scraping is not permitted on the page.
- 404 Not Found, if No Such Element found corresponding to get Page by URL request.
- 504 Gateway Timeout , if request takes longer than 6000 ms.
----

### Page Sentiment ###
----
The API connects to `aylien.com` sentiment analysis API to retrieve sentiment data corresponding to a webpage.
----

### Page Metadata ###
---
The API uses JSOUP library to parse HTML contents of the page to retrieve page metadata.
---
 
### Database Layer ###
---
The API uses `JPA+H2` for database layer.
