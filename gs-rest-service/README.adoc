# Getting Started

### Web Page Sentiment Analyser
RESTful service to parse an Web URL for sentiment analysis and output the results. Store the result in database. Allow search by url to retrieve the result for a URL.


### Pre-requisites

- Unzip the zipped project folder.
- Import the project into IntelliJ
- Run as SpringBoot application (Main Class: SpringBootApplication.java)
- Using REST Client, access API endpoints

### API Endpoints
* POST http://localhost:8080/data/

  Sample Payload:
  {"url":"https://www.google.com"}
  
  Sample Response: {
    "page_title": "Google",
    "description": "Search the world's information, including webpages, images, videos and more. Google has many special features to help you find exactly what you're looking for.",
    "author": "unknown",
    "polarity": "negative",
    "subjectivity": "subjective",
    "text": "Choose the privacy settings that are right for you",
    "polarity_confidence": 0.4907958507537842,
    "subjectivity_confidence": 1,
    "url": "https://www.google.com"
}
API to parse a Web URL and analyse for sentiment and store the results to the Dabatase.

* GET http://localhost:8080/data?url=https://www.netflix.com

  Sample Response: {

    "description": "Search the world's information, including webpages, images, videos and more. Google has many special features to help you find exactly what you're looking for.",
    "author": "unknown",
    "polarity": "negative",

    "text": "Choose the privacy settings that are right for you",
    "polarity_confidence": 0.4907958507537842,

Retrieve Webpage Data from database.

### HTTP Status Codes

 The application supports following HTTPS Status Codes:
  * 200 OK Success
  * 400 Bad Request, if request contains invalid arguments.
  * 403 Forbidden, if data scraping is not permitted on the page.
  * 404 Not Found, if No Such Element found corresponding to get Page by URL request.
  * 504 Gateway Timeout , if request takes longer than 6000 ms.


### Exception Handling
Handled via @ControllerAdvice Spring Exception Handling.
Various Error Scenarior supported

### Technologies used
1. Spring Boot Framework and Java as programming language.
2. The API connects to `aylien.com` sentiment analysis API to retrieve sentiment data corresponding to a webpage.
3. The API uses `JSOUP` library to parse HTML contents of the page to retrieve page metadata.
4. The API uses `JPA+H2` for database layer.
