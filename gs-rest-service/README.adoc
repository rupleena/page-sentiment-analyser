### This guide walks you through the process of Using this REST APPLICATION.###

### API Support 2 REST End points as described below:###
----
1. DESCRIPTION: API to parse a Web URL and analyse for sentiment and store the results to the Dabatase.
   METHOD: POST
   URL: http://localhost:8080/data/
   PAYLOAD: {"url":"https://www.google.com"}
   OUTPUT:
{
    "page_title": "Google",
    "description": "Search the world's information, including webpages, images, videos and more. Google has many special features to help you find exactly what you're looking for.",
    "author": "unknown",
    "polarity": "negative",
    "subjectivity": "subjective",
    "text": "Choose the privacy settings that are right for you",
    "polarity_confidence": 0.4907958507537842,
    "subjectivity_confidence": 1,
    "url": "https://www.google.com"
}


2. DESCRIPTION: Retrieve Webpage Data from database.
   METHOD: GET
   URL: http://localhost:8080/data?url=https://www.netflix.com
   OUTPUT: The response is JSON representation of Page Data stored in the database for the Url:
{
    "page_title": "Netflix - Watch TV Shows Online, Watch Movies Online",
    "description": "Watch Netflix movies & TV shows online or stream right to your smart TV, game console, PC, Mac, mobile, tablet and more.",
    "author": "unknown",
    "polarity": "neutral",
    "subjectivity": "subjective",
    "text": "Watch on your TV Smart TVs, PlayStation, Xbox, Chromecast, Apple TV, Blu-ray players and more.Watch instantly or download for later Available on phone and tablet, wherever you go.",
    "polarity_confidence": 0.5351378917694092,

    "url": "https://www.netflix.com"
}

### HTTP Status Codes ###
The application supports following HTTPS Status Codes:
- 200 OK Success
- 400 Bad Request, if request contains invalid arguments.
- 403 Forbidden, if data scraping is not permitted on the page.
- 404 Not Found, if No Such Element found corresponding to get Page by URL request.
- 504 Gateway Timeout , if request takes longer than 6000 ms.
----

----
### Technologies used ###
1. Spring Boot Framework and Java as programming language.
2. The API connects to `aylien.com` sentiment analysis API to retrieve sentiment data corresponding to a webpage.
3. The API uses `JSOUP` library to parse HTML contents of the page to retrieve page metadata.
4. The API uses `JPA+H2` for database layer.
